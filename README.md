# QRKot

## Описание

API-сервис для благотворительного фонда поддержки котиков. Система позволяет управлять благотворительными проектами и пожертвованиями.

## Возможности

1. **Управление пользователями**
   - Регистрация и аутентификация пользователей
   - Разделение прав доступа (обычные пользователи и суперпользователи)

2. **Благотворительные проекты**
   - Создание, редактирование и удаление проектов (только для суперпользователей)
   - Автоматическое распределение пожертвований по проектам
   - Отслеживание прогресса сбора средств
   - Закрытие проектов при полном сборе средств

3. **Пожертвования**
   - Создание пожертвований (доступно всем авторизованным пользователям)
   - Просмотр собственных пожертвований
   - Автоматическое инвестирование средств в открытые проекты

4. **Инвестиционный механизм**
   - Автоматическое распределение новых пожертвований по открытым проектам
   - Распределение средств при создании новых проектов
   - Закрытие проектов и пожертвований при полном финансировании

## Запуск проекта

### Клонирование репозитория
```
git clone <repo-url>
```

```
cd cat-charity-2
```
### Создание виртуального окружения
```
python -m venv venv
```

```
source venv/Scripts/activate
```
### Установка зависимостей
```
pip install -r requirements.txt
```
### Применение миграций
```
alembic upgrade head
```
### Запуск
```
uvicorn app.main:app --reload
```
